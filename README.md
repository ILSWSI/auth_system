# __msvc_bit_utils.hpp

## Общее описание

Файл `__msvc_bit_utils.hpp` является внутренним заголовком стандартной библиотеки Microsoft C++ (MSVC STL). Он предоставляет низкоуровневые утилиты для битовых операций над целыми числами без знака. Код оптимизирован для различных архитектур (x86, x64, ARM, ARM64) и использует аппаратные инструкции (LZCNT, TZCNT, POPCNT, BSR, BSF), если они доступны, с откатом к программным реализациям.

Данный заголовок **не предназначен для прямого использования** в пользовательском коде — он используется внутри реализации `<bit>`, `<numeric>` и других компонентов стандартной библиотеки.

## Основные возможности

- **Подсчёт ведущих нулей** (`countl_zero`)
- **Подсчёт завершающих нулей** (`countr_zero`)
- **Подсчёт единичных битов** (`popcount`)

Для каждого из этих семейств реализованы:
- программные реализации (алгоритмы из книги «Hacker's Delight»), работающие на всех платформах и на этапе компиляции (`constexpr`);
- варианты с использованием аппаратных инструкций (LZCNT, TZCNT, POPCNT, BSR, BSF) для максимальной производительности во время выполнения;
- условный выбор между ними в зависимости от доступных инструкций (определяется через глобальную переменную `__isa_available` и макросы целевой архитектуры).

## Особенности реализации

- **Платформо-зависимая диспетчеризация**: используется макрос `_HAS_COUNTL_ZERO_INTRINSICS` и аналогичные для управления доступностью интринсиков.
- **x86/x64**: применяются интринсики `__lzcnt`, `__lzcnt16`, `__lzcnt64`, `__tzcnt_u32`, `__tzcnt_u64`, `__popcnt`, `__popcnt64`; для старых процессоров — `_BitScanForward`, `_BitScanReverse`.
- **ARM/ARM64**: используются интринсики `_CountLeadingZeros`, `_CountLeadingZeros64`.
- **Поддержка constexpr**: в C++20 и новее функции используют `is_constant_evaluated()` для выбора программной реализации во время компиляции, даже если доступны интринсики.
- **Лицензия**: Apache-2.0 WITH LLVM-exception.

## Содержимое файла

Заголовок определяет:
- Внутренние константы `_Stl_isa_available_sse42`, `_Stl_isa_available_avx2`;
- Вспомогательный шаблон `_Unsigned_integer_digits`;
- Функции fallback:
  - `_Countl_zero_fallback`
  - `_Countr_zero_fallback`
  - `_Popcount_fallback`
- Функции с использованием интринсиков:
  - `_Countl_zero_lzcnt`, `_Countl_zero_bsr`, `_Checked_x86_x64_countl_zero`
  - `_Countr_zero_tzcnt`, `_Countr_zero_bsf`, `_Checked_x86_x64_countr_zero`
  - `_Unchecked_popcount`, `_Checked_popcount`
- Основные публичные (для внутреннего использования) функции:
  - `_Countr_zero`
  - `_Popcount`
- Шаблоны `_Select_countr_zero_impl`, `_Select_popcount_impl`, которые выбирают оптимальную реализацию для переданного callback.

## Использование

Внутри библиотеки MSVC STL эти утилиты используются через функции `_Countr_zero` и `_Popcount`, которые автоматически вызывают наиболее эффективную версию для целевой платформы и контекста (компиляция или выполнение).

Пример вызова:
```cpp
unsigned int x = 0b1000;
int zeros = _Countr_zero(x); // вернёт 3
int ones = _Popcount(x);     // вернёт 1
